## 📋 Fonctionnalités Démontrées

| Module | Description |
|--------|-------------|
| 📊 **Tableau de Bord** | Vue d'ensemble avec KPIs en temps réel, graphiques de recrutement et alertes CDD |
| 👥 **Gestion des Employés** | Ajout, modification, suppression, filtrage par statut (Actif, En Congé, Maladie) |
| 🗓️ **Congés & Absences** | Saisie avec détection automatique de chevauchement, historique complet |
| 📈 **Statistiques & Analytics** | Graphiques interactifs (Chart.js) : contrats, retards, absences |
| 💰 **Finance & Paie** | Calculateur de paie conforme à la législation algérienne (CNAS 9%, IRG) avec génération de bulletin de paye |
| 📱 **WhatsApp / SMS** | Envoi de notifications directes aux employés via WhatsApp Web |
| 📧 **Microsoft Outlook** | Simulation d'envoi d'emails automatisés via le connecteur MAPI |

## 🛠️ Stack Technique

- **Frontend** : HTML5 / CSS3 / JavaScript ES6 (Vanilla)
- **Charts** : Chart.js
- **Fonts** : Inter (Google Fonts)
- **Icons** : Font Awesome 6
- **Storage** : localStorage (mode démo, aucune base de données requise)
- **Hébergement** : GitHub Pages (100% gratuit)

## 📱 Responsive

L'application est optimisée pour desktop et tablette.
